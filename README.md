# RONO-V2.py
RONOAI Network Monitor

أداة لمراقبة حركة الشبكة باستخدام Python وScapy، مع واجهة تفاعلية تعمل من الطرفية.

⚠️ تنبيه

هذا المشروع مخصص للتعلم والاختبار داخل الشبكات والأجهزة التي تملكها أو لديك تصريح صريح لاختبارها.

لا تستخدم الأداة لاعتراض بيانات أو حسابات أو حركة مرور أشخاص آخرين دون إذن.

✨ المميزات

- مراقبة استعلامات DNS.
- عرض النطاقات التي يتم طلبها.
- دعم Scapy لالتقاط حزم الشبكة.
- واجهة Terminal ملونة باستخدام Colorama.
- اكتشاف عناوين MAC.
- دعم Linux.
- وضع مراقبة للشبكة.
- خيارات اختبار DNS مخصصة لبيئة المختبر.

🛠️ المتطلبات

- Python 3
- Scapy
- Colorama
- نظام Linux مناسب للاختبارات الشبكية

📦 التثبيت

pip install scapy colorama

▶️ التشغيل

sudo python3 ronoai.py

يجب تشغيل البرنامج بصلاحيات مناسبة لأن Scapy يحتاج إلى صلاحيات للوصول إلى واجهة الشبكة والتقاط الحزم.
